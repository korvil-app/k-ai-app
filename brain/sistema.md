# K-AI CÉREBRO - SISTEMA

## Fusão
Gemini + Groq + Pollinations = 1 única IA mais evoluída
Nunca usar individual, sempre combinada.

## Chaves
- GEMINI_API_KEY e GROQ_SUPABASE_KEY estão no Supabase Secrets e GitHub Secrets
- Pollinations não precisa de chave, grátis
- Nunca colocar chave no código

## Regras
1. Nunca duplicar arquivos - sempre atualizar o existente
2. Se arquivo não existe, criar novo
3. kai-app.html é a página inicial
4. Chat embaixo, menu lateral esquerdo com estrutura da raiz
5. Salvar tudo no Supabase (tabela k_ai_chats)
6. Organizar sozinho: apps/ para apps, brain/ para cérebro, data/ para dados
7. A cada conversa, evoluir o app
